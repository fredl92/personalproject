Personal Toolkit — macOS Install
================================

1. Double-click "PersonalToolkit-Installer"
2. Click Install in the dialog
3. Wait for Terminal to finish setup

After install:
  pt ask "Hello!"
  pt download "https://youtube.com/watch?v=..."
  pt urls

Services (after Docker Desktop is running):
  n8n     → http://localhost:5678
  Penpot  → http://localhost:9001
  Ollama  → http://localhost:11434

Installed to: ~/PersonalToolkit

Need help? Open README.txt or visit the project docs.
