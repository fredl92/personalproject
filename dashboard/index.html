Wat wil je doen?

Kies een taak. Je toolkit helpt je op weg.

De app-links konden niet worden geladen. Voer pt dashboard opnieuw uit in Terminal en herlaad deze pagina. Je kunt hieronder wel een commando voor je taak maken.

Je volgende stap

Samenvatting maken

Uitvoeren doe je daarna in Terminal.

Klaar om uit te voeren

Kopieer dit commando, plak het in Terminal en druk op Enter.

Waar vind ik Terminal?

Druk op ⌘ + spatie, typ Terminal en druk op Enter. Plak met ⌘ + V.

Mijn bestandspad vinden

Selecteer je opname in Finder. Druk op ⌥ + ⌘ + C om het volledige pad te kopiëren. Plak dat in het invoerveld.

Je invoer wordt niet in dit dashboard opgeslagen.
